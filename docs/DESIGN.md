# Reference lock

Build target: EJRA Smiles & Wellness public booking flow and staff entry, adapted to the existing Smile U Love brand and real clinic images. Refero live research was attempted; the account returned NO_SUBSCRIPTION. Used the bundled craft-details and visual-workflow guidance instead.

Primary direction: Smile U Love's pink/teal identity, white canvas, readable dark text, real clinic photography. Preserve the existing clinic logo and factual service list. Pink belongs to booking actions; teal to clinic information. No invented testimonials, dentist names or availability.

Borrow only: EJRA's persistent staff-login link, simple service-to-booking navigation, direct request language, and appointment overview. Do not copy its educational lead/BST screens.

Tokens: white and #fff7fa backgrounds, #253d43 ink, #b92762 action, #16788a secondary, 12px field radius, 22px panel radius. System sans body; Georgia full headings (no decorative word swaps). Actual clinic photos with fixed aspect ratios.

Decision ledger:
- Header services / book / admin: user and EJRA reference; separates visitor and staff tasks.
- Two-column clinic introduction and photography: EJRA composition plus real Smile U Love asset; keeps clinic context without a phone mockup.
- One-page grouped form: EJRA flow; avoids unnecessary accounts and steps.
- Explicit pending receipt: existing confirmation workflow; a request is never presented as a confirmed appointment.
- Admin filters, dated requests, contact details: existing staff workflow; efficient review, empty/loading/error states.
- Visible focus, labels, 44px targets, 16px inputs: Refero craft reference; keyboard and mobile usability.

Visual QA: desktop public page and authenticated dashboard inspected in the browser against the reference lock. The clinic photos, pink action role, teal labels, typography hierarchy and separate admin navigation are present. Mobile screenshot verification was blocked by an approval-review usage limit; responsive CSS is implemented but its mobile render remains unverified.
